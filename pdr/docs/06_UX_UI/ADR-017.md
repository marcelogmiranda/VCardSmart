# ADR-017 — Mobile UX First

| Campo | Valor |
|-------|-------|
| **Status** | Aceita |
| **Projeto** | VCardSmart |
| **Última atualização** | 2026-07-13 |

---

## Decisão

Todo o design do VCardSmart será pensado prioritariamente para smartphones.

---

## Regras

| # | Regra |
|---|-------|
| 1 | Primeiro para telas de 6" a 6.8" |
| 2 | Adaptação para tablets e dobráveis |
| 3 | Interface utilizável com uma mão sempre que possível |
| 4 | Navegação consistente entre Android e iOS |
| 5 | Respeitar diretrizes de cada plataforma |
| 6 | Nenhuma funcionalidade crítica dependerá exclusivamente de gestos |

---

## Justificativa

| # | Justificativa |
|---|---------------|
| 1 | Maioria dos usuários utiliza smartphones |
| 2 | Networking é feito em movimento |
| 3 | Uma mão é utilizada frequentemente |
| 4 | Consistência entre plataformas |

---

## Consequências

### Positivas
- ✅ Experiência otimizada para o caso de uso principal
- ✅ Interface mais intuitiva
- ✅ Maior alcance de usuários

### Negativas
- ❌ Necessidade de adaptação para tablets
- ❌ Testes em múltiplos tamanhos de tela
