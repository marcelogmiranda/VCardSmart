## Descrição das Telas Principais

### HomeScreen
- Cartão do perfil (ProfileCard)
- Ação: Compartilhar
- Ação: Editar
- Lista de cartões recebidos
- Navegação inferior

### ProfileScreen
- Foto do perfil
- Nome, cargo, empresa
- Redes sociais
- Botão compartilhar

### ShareScreen
- QR Code
- NFC
- WhatsApp
- vCard

### SettingsScreen
- Idioma
- Tema
- Segurança
- Sobre
- Licenças
