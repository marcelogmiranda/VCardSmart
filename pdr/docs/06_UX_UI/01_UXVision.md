## Princípios

| Princípio | Descrição |
|-----------|-----------|
| **Simplicidade** | Interface limpa e direta, sem elementos desnecessários |
| **Rapidez** | Máximo 3 toques para qualquer função |
| **Interface Limpa** | Foco no conteúdo, sem distrações |
| **Material Design 3** | Seguir diretrizes do Google |
| **Navegação Intuitiva** | Qualquer pessoa navega sem tutorial |
| **Feedback Visual** | Toda ação possui retorno visual imediato |
| **Offline First** | Experiência completa sem internet |

---

## Objetivos de UX

| Objetivo | Métrica |
|----------|---------|
| Primeira utilização completa | < 2 minutos |
| Compartilhamento | < 10 segundos (3 toques) |
| Edição de perfil | < 30 segundos |
| Aprender a usar | Sem tutorial |

---

## Regras de UX

| # | Regra |
|---|-------|
| 1 | Máximo 3 toques para qualquer ação principal |
| 2 | Sempre mostrar feedback visual |
| 3 | Sempre confirmar ações destrutivas |
| 4 | Sempre oferecer volta/cancelar |
| 5 | Interface utilizável com uma mão |
| 6 | Sem dependência exclusiva de cores |
| 7 | Sempre mostrar estado (loading, erro, vazio) |
