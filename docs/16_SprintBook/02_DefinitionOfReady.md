# Definition of Ready — VCardSmart

## Visão Geral

Uma Sprint está pronta para começar quando todos os critérios abaixo são atendidos.

## Critérios

### 1. Documentação

- [ ] README lido
- [ ] Architecture.md lido
- [ ] Acceptance Criteria definidos
- [ ] Sprint atual documentada
- [ ] Dependências identificadas

### 2. Requisitos

- [ ] User stories claras
- [ ] Critérios de aceitação definidos
- [ ] Prioridade definida
- [ ] Estimativa de esforço

### 3. Design

- [ ] Wireframes prontos (se necessário)
- [ ] Fluxos definidos
- [ ] Componentes identificados
- [ ] Integrações mapeadas

### 4. Técnico

- [ ] Arquitetura definida
- [ ] Dependências identificadas
- [ ] APIs documentadas (se necessário)
- [ ] Dados modelados

### 5. Testes

- [ ] Casos de teste definidos
- [ ] Dados de teste prontos
- [ ] Ambiente de teste configurado

### 6. Ambiente

- [ ] Flutter SDK configurado
- [ ] Dependências instaladas
- [ ] Build funcionando
- [ ] Testes passando

## Checklist de Sprint

### Antes de Começar

- [ ] Todos os critérios atendidos
- [ ] Equipe alinhada
- [ ] Dependências resolvidas
- [ ] Ambiente pronto

### Durante

- [ ] Progresso acompanhado
- [ ] Bloqueios identificados
- [ ] Comunicação ativa
- [ ] Qualidade mantida

### Ao Final

- [ ] Todos os critérios de aceitação atendidos
- [ ] Testes passando
- [ ] Documentação atualizada
- [ ] Código revisado

## Formato de Sprint

### Estrutura

```
Sprint [número] - [Nome]

Objetivo: [objetivo]

Pré-requisitos:
- [pré-requisito 1]
- [pré-requisito 2]

Entregas:
- [entrega 1]
- [entrega 2]

Critérios de Aceitação:
- [critério 1]
- [critério 2]

Estimativa: [X dias]
```

## Validação

### Product Owner

- [ ] Requisitos claros
- [ ] Prioridade confirmada
- [ ] Critérios de aceitação aprovados

### Tech Lead

- [ ] Arquitetura definida
- [ ] Dependências mapeadas
- [ ] Estimativa validada

### QA

- [ ] Casos de teste definidos
- [ ] Dados de teste prontos
- [ ] Ambiente configurado
