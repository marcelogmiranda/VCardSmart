## Termos Técnicos

| Termo | Definição |
|-------|-----------|
| **Hive** | Banco de dados leve e rápido para Flutter, armazenamento local |
| **Riverpod** | Gerenciamento de estado para Flutter, sucessor do Provider |
| **GoRouter** | Sistema de roteamento declarativo para Flutter |
| **NFC** | Near Field Communication, tecnologia de comunicação sem fio de curta distância |
| **QR Code** | Código bidimensional para armazenamento de dados |
| **vCard** | Formato padrão para cartões de visita digitais (RFC 6350) |
| **Material Design** | Sistema de design criado pelo Google |
| **Clean Architecture** | Arquitetura de software que separa responsabilidades em camadas |
| **SOLID** | Princípios de design orientado a objeto |
| **ARB** | Application Resource Bundle, formato de internationalização do Flutter |
| **AdMob** | Plataforma de anúncios mobile do Google |
| **Biometria** | Autenticação por características físicas (impressão digital, Face ID) |

## Termos do Projeto

| Termo | Definição |
|-------|-----------|
| **Cartão** | Perfil profissional do usuário no app |
| **Compartilhamento** | Ato de enviar o cartão para outro dispositivo |
| **Importação** | Ato de receber e salvar um cartão de outro dispositivo |
| **Perfil** | Dados profissionais do usuário (nome, cargo, empresa, etc.) |
| **Offline First** | Princípio de que o app funciona 100% sem internet |
| **Privacy First** | Princípio de que a privacidade é a prioridade máxima |
