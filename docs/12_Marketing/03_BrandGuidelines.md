# Brand Guidelines — VCardSmart

## Diretrizes da Marca

### Propósito

Garantir consistência na comunicação visual e textual do VCardSmart em todos os canais e formatos.

### Escopo

Aplica-se a:
- Materiais de marketing
- Store listings
- Website
- Redes sociais
- Documentação
- Comunicação interna

## Tom de Voz

### Características

| Característica | Descrição |
|----------------|-----------|
| Profissional | Comunicação séria e respeitosa |
| Objetivo | Direto, conciso, sem rodeios |
| Confiável | Transmite segurança e credibilidade |
| Minimalista | Simples, limpo, organizado |

### Regras

1. **Nunca** usar linguagem exagerada
2. **Nunca** fazer promessas impossíveis
3. **Sempre** ser honesto e transparente
4. **Sempre** manter tom profissional
5. **Sempre** ser claro e conciso

### Exemplos

#### ✅ Adequado

```markdown
# Criar Perfil

1. Preencha seus dados básicos
2. Adicione suas redes sociais
3. Toque em Salvar

Pronto! Seu cartão está pronto para compartilhar.
```

```markdown
# Privacidade

Seus dados nunca saem do dispositivo.
Não coletamos informações pessoais.
Não utilizamos analytics.
```

#### ❌ Inadequado

```markdown
# Crie seu perfil AGORA!

É super fácil e rápido!
Você vai amar!
Não perca essa oportunidade!
```

```markdown
# Política de Privacidade

Respeitamos sua privacidade (mais ou menos).
Não coletamos muitos dados (só alguns).
```

## Cores

### Paleta Oficial

| Cor | Código | Uso |
|-----|--------|-----|
| Azul primário | #1976D2 | CTAs, destaques |
| Azul escuro | #1565C0 | Hover, pressed |
| Branco | #FFFFFF | Fundo claro |
| Cinza claro | #F5F5F5 | Superfície |
| Cinza | #757575 | Texto secundário |
| Cinza escuro | #424242 | Texto primário |
| Preto | #212121 | Texto em fundo claro |
| Verde | #4CAF50 | Sucesso |
| Vermelho | #F44336 | Erro |

### Regras de Uso

1. **Azul primário** para CTAs e elementos principais
2. **Branco/Cinza** para fundos
3. **Verde** apenas para sucesso
4. **Vermelho** apenas para erros
5. **Nunca** usar mais de 3 cores em um elemento

### Hierarquia

| Nível | Tamanho | Peso | Uso |
|-------|---------|------|-----|
| H1 | 24sp | Bold | Títulos de página |
| H2 | 20sp | Bold | Subtítulos |
| H3 | 16sp | Medium | Seções |

### Regras

1. **Nunca** usar mais de 2 tamanhos em um elemento
2. **Sempre** manter hierarquia clara
3. **Nunca** usar negrito excessivo
4. **Sempre** usar espaçamento adequado

## Imagens

### Screenshots

| Loja | Resolução | Proporção |
|------|-----------|-----------|
| Google Play | 1080x1920 | 9:16 |
| Apple App Store | 1170x2532 | 9:16 |

### Feature Graphic

| Loja | Resolução |
|------|-----------|
| Google Play | 1024x500 |
| Website | 1200x630 |

### Regras

1. **Sempre** usar resolução adequada
2. **Nunca** esticar ou comprimir
3. **Sempre** manter proporção
4. **Nunca** adicionar texto excessivo

## Texto em Imagens

### Regras

1. **Nunca** usar mais de 2 linhas
2. **Sempre** usar fonte legível
3. **Nunca** usar efeitos especiais
4. **Sempre** manter contraste adequado

## Consistência

### Checklist

- [ ] Cores da paleta oficial
- [ ] Tipografia correta
- [ ] Ícones Material Design
- [ ] Espaçamento consistente
- [ ] Bordas e elevação corretas
- [ ] Tom de voz profissional
- [ ] Sem linguagem exagerada
- [ ] Imagens na resolução correta

## Exceções

### Quando Alterar

- Adaptação para acessibilidade
- Adaptação para diferentes tamanhos
- Adaptação para diferentes idiomas
- Adaptação para tema claro/escuro

### Como Alterar

1. Manter essência da marca
2. Manter consistência visual
3. Documentar mudança
4. Aprovar com responsável
