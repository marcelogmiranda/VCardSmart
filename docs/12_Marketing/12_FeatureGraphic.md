## Regras

### Geral

1. **Sempre** usar resolução 1024x500
2. **Nunca** distorcer elementos
3. **Sempre** manter legibilidade
4. **Nunca** usar texto excessivo

### Logo

1. **Sempre** manter proporção
2. **Nunca** distorcer
3. **Sempre** usar cores oficiais
4. **Nunca** adicionar efeitos

### Texto

1. **Máximo** 2 linhas
2. **Sempre** fonte legível
3. **Nunca** usar efeitos
4. **Sempre** contraste adequado
