Central de suporte para auxiliar usuários com dúvidas, sugestões e problemas.

## FAQ

### Perguntas Frequentes

#### Geral

| Pergunta | Resposta |
|----------|----------|
| O que é VCardSmart? | Cartão de visitas digital offline |
| Como funciona? | Crie perfil, compartilhe via QR/NFC |
| É seguro? | Sim, dados criptografados localmente |
| Precisa de internet? | Não, 100% offline |
| Precisa de conta? | Não, sem login |
| É gratuito? | Sim, com anúncios |

#### Funcionalidades

| Pergunta | Resposta |
|----------|----------|
| Como criar perfil? | Abra o app, toque em "Criar Perfil" |
| Como compartilhar via QR Code? | Acesse perfil, toque em "Compartilhar" |
| Como compartilhar via NFC? | Acesse perfil, ative NFC, aproxime dispositivos |
| Como importar contato? | Toque em "Importar", escaneie QR Code |
| Como alterar tema? | Acesse "Configurações" > "Tema" |
| Como excluir dados? | Acesse "Configurações" > "Excluir Dados" |

#### Segurança

| Pergunta | Resposta |
|----------|----------|
| Meus dados estão seguros? | Sim, criptografados localmente |
| Você coletam meus dados? | Não, sem coleta |
| Como proteger meu perfil? | Use biometria ou PIN |
| O que acontece se perder o dispositivo? | Dados ficam inacessíveis |

## Processo

### 1. Recebimento

- Usuário envia formulário
- Sistema registra ticket
- Notificação para equipe

### 2. Análise

- Equipe analisa solicitação
- Classifica prioridade
- Identifica responsável

### 3. Resolução

- Implementa solução
- Testa mudança
- Publica atualização

### 4. Feedback

- Notifica usuário
- Fecha ticket
- Documenta solução
