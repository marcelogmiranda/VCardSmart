## Regras de Design

### Geral

1. **Nunca** usar texto excessivo
2. **Sempre** mostrar funcionalidade real
3. **Nunca** usar mockups genéricos
4. **Sempre** manter consistência visual
5. **Sempre** usar resolução adequada

### Texto

1. **Máximo** 2 linhas de texto
2. **Sempre** fonte legível
3. **Nunca** usar efeitos especiais
4. **Sempre** contraste adequado

### Elementos

1. **Sempre** usar ícones Material Design
2. **Nunca** usar imagens de stock
3. **Sempre** manter alinhamento
4. **Nunca** usar bordas coloridas

## Produção

### Ferramentas

| Ferramenta | Uso |
|------------|-----|
| Figma | Design |
| Device Frames | Mockups |
| Screenshot tools | Captura |

### Processo

1. Criar design no Figma
2. Aplicar em device frames
3. Capturar screenshots
4. Revisar qualidade
5. Exportar na resolução correta
