## Visão Geral

Técnicas para otimizar o uso de contexto em prompts de IA.

## Por que Comprimir

- Tokens limitados

- Qualidade do output

### Soluções

- Formatação otimizada

## Exemplo

### Antes (Completo)

```
O VCardSmart é um aplicativo Flutter para cartão de visitas digital offline.
Ele utiliza Riverpod para gerenciamento de estado, GoRouter para navegação,
Hive com criptografia AES-256 para armazenamento local, e Material Design 3
para interface. O projeto segue Clean Architecture e está disponível para
Android (mínimo API 21) e iOS (mínimo 12.0). Suporta 8 idiomas e tem como
princípios: Offline First, Privacy First, e Security First.
```
