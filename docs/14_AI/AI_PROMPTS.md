Aqui está um diferencial importante em relação a projetos tradicionais.

Em vez de um único prompt enorme, teremos prompts especializados, cada um responsável por um módulo específico.

Exemplo:

Prompt 001

Criar o workspace Flutter.

Prompt 002

Criar a Clean Architecture.

Prompt 003

Criar o sistema de temas.

Prompt 004

Criar a internacionalização.

Prompt 005

Criar o banco Hive.

…

Cada prompt terá:

objetivo;
contexto;
pré-requisitos;
entradas;
saídas esperadas;
critérios de aceitação;
testes obrigatórios.

Isso permitirá reutilizar os prompts em futuras versões e até substituir o agente de IA sem perder consistência.
