# Biblioteca de Prompts — VCardSmart

## Coleção de Prompts

### Feature Creation

```
Leia toda a documentação.

Implemente somente esta Feature: [nome].

Não altere outras Features.

Crie:
- Entity
- Model
- Repository
- UseCases
- Providers
- Widgets
- Pages
- Tests
- Localization
- Documentation

Execute Analyze
Execute Tests
Atualize CHANGELOG
```

### Bug Fix

```
Corrija apenas os erros: [descrição].

Não refatore.
Não altere APIs.
Não altere documentação.
Não instale novas dependências.
```
