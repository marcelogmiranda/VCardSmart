# Política para Crianças — VCardSmart

## Público Alvo

### Destinatários

- ✅ Público geral
- ✅ Profissionais
- ✅ Empresas
- ❌ Crianças (menores de 13 anos)
- ❌ Adolescentes (13-17 anos, sem supervisão)

## Não Direcionado para Crianças

### Declaração

O VCardSmart **não é direcionado** para crianças menores de 13 anos.

### Razões

1. **Conteúdo profissional** — Cartões de visita são para uso profissional
2. **Funcionalidade** — Não há funcionalidades atraentes para crianças
3. **Dados** — Não coletamos dados de menores
4. **Segurança** — Não oferecemos proteções específicas para crianças

## Dados

### O que NÃO coletamos

- ❌ Idade
- ❌ Data de nascimento
- ❌ Nome de escola
- ❌ Informações de responsáveis
- ❌ Dados pessoais de menores

### Regra

> Não coletamos intencionalmente dados pessoais de crianças menores de 13 anos.

## Caso de Uso Indevido

### Se uma criança usar o app

1. **Não há coleta** — Dados permanecem no dispositivo
2. **Não há risco** — Sem dados enviados
