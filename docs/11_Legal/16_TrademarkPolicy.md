## Uso de Marcas de Terceiros

### Regras

1. **Apenas para identificação** — Não para endosso
2. **Sem modificação** — Manter forma original
3. **Sem uso em logo** — Não combinar com nossa marca
4. **Sem uso comercial** — Não vender produtos com marcas de terceiros
