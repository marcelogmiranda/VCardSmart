# Política de Suporte — VCardSmart

## Canais de Suporte

### Disponíveis

| Canal | Descrição | Disponibilidade |
|-------|-----------|-----------------|
| Formulário interno | Sugestões, melhorias, correções | 24/7 |
| FAQ | Perguntas frequentes | 24/7 |

### Não Disponíveis

| Canal | Motivo |
|-------|--------|
| Suporte telefônico | Recursos limitados |
| Chat ao vivo | Recursos limitados |
| Email direto | Use formulário |

## Tipos de Suporte

### 1. Sugestões

> Ideias para melhorar o aplicativo.

**Processo**:
1. Usuário envia sugestão
2. Equipe avalia
3. Se aprovada, entra no backlog
4. Implementação conforme prioridade

### 2. Melhorias

> Funcionalidades novas ou aprimoradas.

**Processo**:
1. Usuário solicita melhoria
2. Equipe analisa viabilidade
3. Se aprovada, entra no roadmap
4. Implementação conforme planejamento

### 3. Correções

> Bugs ou problemas identificados.

**Processo**:
1. Usuário reporta problema
2. Equipe reproduce e investiga
3. Correção implementada
4. Nova versão publicada

### 4. Dúvidas

> Perguntas sobre uso do aplicativo.

**Processo**:
1. Usuário envia dúvida
2. Equipe responde via FAQ ou formulário
3. Se necessário, documentação atualizada

## FAQ

### Perguntas Frequentes

#### Como criar um perfil?

1. Abra o aplicativo
2. Toque em "Criar Perfil"
3. Preencha os dados
4. Toque em "Salvar"

#### Como compartilhar via QR Code?

1. Acesse seu perfil
2. Toque em "Compartilhar"
3. Selecione "QR Code"
4. Mostre o QR Code para a outra pessoa

#### Como importar um contato?

1. Toque em "Importar"
2. Escaneie o QR Code ou toque no NFC
3. Revise os dados
4. Confirme a importação

#### Como alterar o tema?

1. Acesse "Configurações"
2. Selecione "Tema"
3. Escolha "Claro" ou "Escuro"

#### Como alterar o idioma?

1. Acesse "Configurações"
2. Selecione "Idioma"
3. Escolha o idioma desejado

#### Como excluir meus dados?

1. Acesse "Configurações"
2. Selecione "Excluir Todos os Dados"
3. Confirme a exclusão
