# Termos de Uso — VCardSmart

**Última atualização**: Janeiro 2024

## Aceitação

Ao utilizar o VCardSmart, você concorda com estes Termos de Uso.

## Descrição do Serviço

O VCardSmart é um aplicativo móvel para criação e compartilhamento de cartões de visita digitais.

## Responsabilidades do Usuário

### Informações

- O usuário é responsável pelas informações compartilhadas
- Informações incorretas são de responsabilidade do usuário
- O aplicativo não verifica a veracidade das informações

### Compartilhamento

- Compartilhamento exige confirmação explícita
- O usuário controla o que é compartilhado
- O aplicativo não compartilha automaticamente

### Segurança

- O usuário deve manter o dispositivo seguro
- Biometria e PIN são opcionais
- Perda do dispositivo pode resultar em perda de dados

## Limitações

### Dados Compartilhados

- O aplicativo não garante que terceiros armazenem ou removam informações após recebê-las
- Uma vez compartilhado, o controle sobre os dados é perdido
- Recomendamos cautela ao compartilhar

### Disponibilidade

- O aplicativo funciona offline
- Sem garantia de disponibilidade de funcionalidades nativas (NFC, câmera)
- Atualizações dependentes das lojas oficiais

## Uso Aceitável

### Permitido

- Uso pessoal e comercial
- Compartilhamento de informações profissionais
- Criação de múltiplos perfis (funcionalidade futura)

### Proibido

- Uso ilegal
- Violação de direitos de terceiros
- Engenharia reversa
- Distribuição não autorizada
- Violação de políticas das lojas

O aplicativo não se responsabiliza por:

- Perda do dispositivo
- Uso inadequado
- Compartilhamento indevido realizado pelo usuário

- Danos decorrentes do uso
