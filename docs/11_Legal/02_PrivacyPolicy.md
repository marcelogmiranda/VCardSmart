# Política de Privacidade — VCardSmart

**Última atualização**: Janeiro 2024

## Introdução

O VCardSmart respeita a privacidade dos usuários. Esta política descreve como o aplicativo trata dados pessoais.

## Princípios

- **Privacy by Design** — Privacidade desde o projeto
- **Privacy by Default** — Configuração padrão mais segura
- **Offline First** — Dados permanecem no dispositivo
- **Zero Cloud** — Sem servidores
- **Zero Analytics** — Sem coleta de dados
- **Zero Tracking** — Sem rastreamento

## Dados Coletados

### O que NÃO coletamos

- ❌ Nome do dispositivo
- ❌ IMEI
- ❌ Localização
- ❌ Contatos (exceto com consentimento)
- ❌ Dados de uso
- ❌ Logs de erro
- ❌ Analytics
- ❌ Identificadores únicos

### O que armazenamos localmente

- ✅ Perfil do usuário
- ✅ Configurações
- ✅ Contatos importados (com consentimento)

## Uso dos Dados

| Finalidade | Base Legal |
|------------|------------|
| Funcionamento do app | Legítimo interesse |
| Compartilhamento de perfil | Consentimento |
| Importação de contatos | Consentimento |
| Exportação para agenda | Consentimento |

## Armazenamento

- **Localização**: Exclusivamente no dispositivo
- **Criptografia**: AES-256
- **Chaves**: Flutter Secure Storage
- **Backup**: Não realizado
- **Sincronização**: Não realizada

## Compartilhamento

- ❌ Não compartilhamos com terceiros
- ❌ Não vendemos dados
- ❌ Não enviamos para servidores

### Exceção

- **Google Mobile Ads**: Uso de identificador de publicidade (opt-in)

## Direitos do Usuário

| Direito | Implementação |
|---------|---------------|
| Acesso | Dados sempre acessíveis |
| Correção | Edição permitida |
| Exclusão | Exclusão completa |
| Portabilidade | Exportação em vCard/JSON |
| Informação | Política acessível |
| Consentimento | Explícito e granular |

## Retenção

- Dados mantidos enquanto o app estiver instalado
- Remoção completa na desinstalação
- Sem backup em nuvem

## Segurança

- Criptografia AES-256
- Secure Storage para chaves
- Autenticação biométrica (opcional)
- PIN (opcional)
- Sem logs em produção

## Crianças

- Aplicativo não direcionado para menores
- Não coleta dados de menores
- Não permite uso por menores

## Alterações

- Notificação de mudanças materiais
- Versão da política visível
- Data da última atualização

## Contato

- Canal de suporte disponível
- Sem suporte telefônico
- Resposta em até 30 dias

## Conformidade

- LGPD (Brasil)
- GDPR (Europa)
- Google Play Developer Policy
- Apple App Store Review Guidelines
