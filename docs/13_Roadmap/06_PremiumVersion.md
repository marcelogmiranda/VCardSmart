# Versão Premium — VCardSmart

## Visão Geral

A versão Premium é uma extensão da versão gratuita, oferecendo funcionalidades avançadas para usuários que desejam mais.

## Princípios

1. **Nunca substitui a gratuita**: Premium é uma extensão
2. **Sempre funcional**: Versão gratuita sempre será completa
3. **Valor claro**: Funcionalidades que agregam valor real
4. **Preço justo**: Acessível para o público-alvo
