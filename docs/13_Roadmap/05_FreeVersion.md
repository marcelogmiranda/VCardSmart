# Versão Gratuita — VCardSmart

## Visão Geral

A versão gratuita é o core do produto. Ela sempre será funcional e completa para uso básico.

## Funcionalidades Incluídas

### Core

| Funcionalidade | Descrição |
|----------------|-----------|
| Um cartão | Criar e gerenciar um perfil profissional |
| QR Code | Gerar e compartilhar via QR Code |
| NFC | Compartilhar via NFC |
| vCard | Exportar no formato padrão |
| Agenda | Importar contatos para a agenda do dispositivo |

### Segurança

| Funcionalidade | Descrição |
|----------------|-----------|
| Biometria | Autenticação por impressão digital/rosto |
| PIN | Proteção por PIN numérico |
| Criptografia | Dados criptografados com AES-256 |

### Personalização

| Funcionalidade | Descrição |
|----------------|-----------|
| Idiomas | 8 idiomas suportados |
| Tema | Claro e escuro |
| Layout | Material Design 3 |

### Uso

| Funcionalidade | Descrição |
|----------------|-----------|
| Histórico | Últimos compartilhamentos |
| Sugestões | Canal de feedback |

## Publicidade

### Tipos

| Tipo | Posição | Frequência |
|------|---------|------------|
| Banner | Rodapé de algumas telas | Sempre visível |
| Interstitial | Entre telas (ocasional) | Moderado |

### Regras

| Regra | Descrição |
|-------|-----------|
| ADR-035 | Nunca interromper compartilhamento NFC |
| ADR-035 | Nunca interromper geração de QR Code |
| ADR-035 | Nunca interromper importação de contatos |
| ADR-035 | Nunca interromper autenticação biométrica |
| ADR-035 | Nunca interromper edição do cartão |

### Locais Permitidos

| Local | Tipo |
|-------|------|
