## Componentes do Design System

### Botões
| Componente | Uso |
|-----------|-----|
| **PrimaryButton** | Ação principal (salvar, compartilhar) |
| **SecondaryButton** | Ação secundária (cancelar, voltar) |
| **IconButton** | Ações com ícone (editar, excluir) |
| **TextButton** | Links e ações leves |

### Cards
| Componente | Uso |
|-----------|-----|
| **ProfileCard** | Exibir perfil do usuário |
| **SocialCard** | Exibir rede social |
| **ContactCard** | Exibir contato recebido |

### Inputs
| Componente | Uso |
|-----------|-----|
| **AppTextField** | Campos de texto padronizados |
| **SearchBar** | Busca |

### Feedback
| Componente | Uso |
|-----------|-----|
| **AppDialog** | Diálogos modais |
| **AppSnackbar** | Mensagens temporárias |
| **LoadingIndicator** | Carregamento |
| **EmptyState** | Lista vazia |
| **ErrorState** | Erro |

### Navegação
| Componente | Uso |
|-----------|-----|
| **NavigationBar** | Navegação inferior |
| **AppBar** | Barra superior |
| **ListTile** | Itens de lista |
| **BottomSheet** | Opções |

### Display
| Componente | Uso |
|-----------|-----|
| **Avatar** | Foto do usuário |
| **Logo** | Logotipo |
| **Badge** | Indicadores |

---

## Regras

| # | Regra |
|---|-------|
| 1 | Todos os componentes devem suportar tema claro e escuro |
| 2 | Todos os componentes devem ter estado desabilitado |
| 3 | Todos os componentes devem ter estado de loading |
| 4 | Todos os componentes devem ter estado de erro |
| 5 | Todos os componentes devem ser acessíveis |
| 6 | Todos os componentes devem suportar internacionalização |
| 7 | Todos os componentes devem ter testes de widget |
