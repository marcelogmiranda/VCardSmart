# FAQ — VCardSmart

## Geral

### O que é VCardSmart?

VCardSmart é um cartão de visitas digital offline que respeita sua privacidade. Ele permite compartilhar seu contato profissional via QR Code, NFC ou vCard sem necessidade de internet ou criação de conta.

### É gratuito?

Sim, a versão básica é gratuita com anúncios moderados. Existe uma versão premium sem anúncios e com funcionalidades extras.

### Precisa de internet?

Não. O VCardSmart é 100% offline. Todos os dados ficam armazenados localmente no seu dispositivo.

### Precisa de conta?

Não. Não é necessário criar conta ou fazer login. O app funciona imediatamente após a instalação.

### Meus dados estão seguros?

Sim. Todos os dados são criptografados localmente com AES-256. Nenhum dado é coletado ou enviado para servidores externos.

## Funcionalidades

### Como criar um perfil?

1. Abra o aplicativo
2. Toque em "Criar Perfil"
3. Preencha seus dados
4. Toque em "Salvar"

### Como compartilhar via QR Code?

1. Acesse seu perfil
2. Toque em "Compartilhar"
3. Selecione "QR Code"
4. Mostre o QR Code para a outra pessoa

### Como compartilhar via NFC?

1. Acesse seu perfil
2. Ative o NFC no seu dispositivo
3. Toque em "Compartilhar via NFC"
4. Aproxime os dispositivos

### Como importar um contato?

1. Toque em "Importar"
2. Escaneie o QR Code ou toque no NFC
3. Revise os dados
4. Confirme a importação

### Como alterar o tema?

1. Acesse "Configurações"
2. Selecione "Tema"
3. Escolha "Claro", "Escuro" ou "Sistema"

### Como alterar o idioma?

1. Acesse "Configurações"
2. Selecione "Idioma"
3. Escolha o idioma desejado

### Como excluir meus dados?

1. Acesse "Configurações"
2. Selecione "Excluir Todos os Dados"
3. Confirme a exclusão

## Segurança

### Os dados são enviados para a nuvem?

Não. Todos os dados ficam armazenados localmente no seu dispositivo.

### É possível recuperar dados se perder o dispositivo?

Não. Como os dados ficam apenas no dispositivo, não é possível recuperá-los. Recomendamos fazer backup manual.

### Como proteger meu perfil?

Você pode ativar biometria ou PIN nas configurações.

### O app coleta alguma informação?

Não. O VCardSmart não coleta nenhuma informação pessoal ou de uso.

## Premium

### O que é o Premium?

O Premium é uma versão do app sem anúncios e com funcionalidades extras como múltiplos cartões, templates, backup criptografado, etc.

### Quanto custa?

- Mensal: R$ 9,90
- Anual: R$ 79,90
- Vitalício: R$ 149,90

### Como assinar?

1. Acesse "Configurações"
2. Toque em "Upgrade para Premium"
3. Escolha o plano
4. Confirme a compra

### Posso cancelar?

Sim. Você pode cancelar a qualquer momento nas configurações da loja.

## Suporte

### Como entrar em contato?

Acesse a Central de Suporte no app ou em vcardsmart.app/support.

### Tem suporte telefônico?

Não. O suporte é feito apenas por formulário e FAQ.

### Resposta em quanto tempo?

O tempo de resposta é de até 48 horas.

## Técnico

### Quais plataformas são suportadas?

- Android 5.0 ou superior
- iOS 12.0 ou superior

### O app funciona em tablets?

Sim. O app é responsivo e funciona em tablets.

### Como atualizar o app?

Através da Google Play Store ou App Store.

### Como reportar um bug?

Acesse "Configurações" > "Reportar Problema" ou use o formulário de suporte.
