# ADR-018 — Feature First Modular Architecture

| Campo | Valor |
|-------|-------|
| **Status** | Aceita |
| **Projeto** | VCardSmart |
| **Última atualização** | 2026-07-13 |

---

## Decisão

Todo desenvolvimento será organizado por funcionalidades (Feature First), mantendo a Clean Architecture dentro de cada módulo.

---

## Benefícios

| # | Benefício |
|---|-----------|
| 1 | Alta modularidade |
| 2 | Facilidade de manutenção |
| 3 | Escalabilidade |
| 4 | Reutilização de componentes |
| 5 | Melhor contexto para IA |

---

## Estrutura

```
feature/

└── data/
```
