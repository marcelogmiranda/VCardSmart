## Princípios de Desenvolvimento

| Princípio | Descrição |
|-----------|-----------|
| **Documentação First** | Toda funcionalidade deve ser documentada antes de implementada |
| **AI Driven Development** | IA implementa conforme documentação |
| **Clean Architecture** | Separação estrita de responsabilidades |
| **SOLID** | Princípios de design orientado a objeto |
| **DRY** | Não repetir código |
| **KISS** | Manter simples |
| **YAGNI** | Não implementar o que não será usado |
