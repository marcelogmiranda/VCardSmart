# ADR-019 — OpenCode as Development Agent

| Campo | Valor |
|-------|-------|
| **Status** | Aceita |
| **Projeto** | VCardSmart |
| **Última atualização** | 2026-07-13 |

---

## Decisão

O OpenCode será tratado como o agente oficial de implementação.

---

## Responsabilidades

| # | Responsabilidade |
|---|-----------------|
| 1 | Implementar conforme documentação |
| 2 | Não tomar decisões arquitetônicas sem atualização documental |
| 3 | Executar validações automáticas |
| 4 | Manter conformidade com a Definition of Done |

---

## Regras

| # | Regra |
|---|-------|
| 1 | Seguir documentação existente |
| 2 | Não criar código não documentado |
| 3 | Sempre rodar testes antes de commitar |
| 4 | Atualizar CHANGELOG |
| 5 | Abrir PR para revisão |
